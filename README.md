# SciOly-EV
Code for electric vehicle event for science olympiad 2026-2027
Arduino code for Science Olympiad EV, original code by MY. This code is used to design, control, testing, and performance optimization

Project Overview:
This project involved the build and programming of an EV using an Arduino chip. No kit was utilized, and the design was my own.  I did use ideas from TopFinishKits.com, but needed to modify to fit the correct dimensions, and a button to start with a #2 pencil per rules, and design my own water bottle catch.
