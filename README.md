# SciOly-EV
Code for electric vehicle event for science olympiad 2026-2027
Arduino code for Science Olympiad EV, original code by MY. This code is used to design, control, testing, and performance optimization

Project Overview:
This project involved the build and programming of an EV using an Arduino chip. No kit was utilized, and the design was my own.  I did use ideas from TopFinishKits.com and a template for the car structure, but needed to modify to fit the correct dimensions, and add a button to start runs with a #2 pencil per rules, and design my own water bottle catch.

Materials:

Motor--DC Motor

Motor Driver

Controller--Arduino


# Objective:

My goal to design and build an electric-powered car that will travel 7-10 m (distance determined during the competition). The car will also push a water bottle set 2 m in front of the start 20.0 cmpast the finish distance. The program will be easily adjusted when the target distance is provided. Wiring will be clear and efficient and the mechanical design will allow the car to travel straight and without failure.

# Engineering Process

The project will document:

Hardware and system design

Motor-control programming

Calibration and measurement

Testing and performance analysis

Design improvements based on results
